# Multi-Agent Interaction Architecture Explained

This document explains how the AI agents and technical modules in the **Multi-Agent Generative Media Pipeline (GenMedia-Omni)** interact with each other to produce seamless 30-second multi-shot videos.

---

## 🤖 Agent Interaction Architecture Overview

In our system (`src/agents/stitcher_graph.py`), agents communicate through **Shared Session State** (`PipelineState` in `src/state.py`) and structured **Feedback / Hand-off Chains**.

## 🔄 The 4 Core Interaction Mechanisms

### 1. Communication via Centralized State (`PipelineState`)
Instead of sending unstructured raw text to each other, agents read and mutate a shared Pydantic state object (`src/state.py`):
- **Screenwriter Agent** populates `state.screenplay_draft`.
- **Storyboarder Agent** reads `state.screenplay_draft` and populates `state.storyboard` and `state.shots`.
- **Prompt Optimizer Agent** reads `state.storyboard` entries and updates `shot.prompt`.
- **Health Checker Agent** audits `shot.prompt`.
- **Quality Rater Agent** evaluates clips and records `state.quality_rating`.
- **OpenCV Video Parser** populates `shot.extracted_last_frame_b64`.

---

### 2. Pre-Production Sequential Hand-Off
1. **Screenwriter ➔ Storyboarder:**
   - **Hand-off:** Screenwriter outputs a 3-act narrative text script.
   - **Interaction:** The Storyboarder receives this script, parses the narrative structure, and generates structured JSON specifying camera angles (`wide`, `medium`, `close-up`), subject details, and motion parameters.

2. **Storyboarder ➔ Prompt Optimizer:**
   - **Hand-off:** Storyboarder outputs JSON shot specs.
   - **Interaction:** The Prompt Optimizer enriches each JSON spec into a cinematic prompt optimized specifically for Gemini Omni Flash's multimodal transformer backend.

---

### 3. Production Feedback & Quality Loop (`src/agents/stitcher_graph.py`)

1. **Prompt Optimizer ➔ Health Checker Agent (`audit_prompt_health`):**
   - **Interaction:** Prompt Optimizer submits candidate prompts to the Health Checker. The Health Checker audits the prompt against safety policies and structural format guardrails before calling the model API.

2. **Quality Rater Agent ➔ Prompt Optimizer (`evaluate_clip_quality`):**
   - **Interaction:** After a clip is generated by Gemini Omni Flash, the Quality Rater inspects it and outputs a quality score ($0.0 - 1.0$) and feedback string.
   - **Feedback Trigger:** If `score < 0.8` and `attempt < max_attempts`, the Quality Rater outputs actionable feedback (e.g., *"Lighting inconsistent with Shot 1; character goggles missing"*).
   - **Re-attempt Routing:** The feedback is routed back to `optimize_prompt(raw_prompt, feedback=feedback)` to adjust the prompt for a re-attempt (`state.attempt_counter += 1`).

---

### 4. Cross-Modal Hand-Off (OpenCV Parser ➔ Gemini Omni Flash)
For **Sequential Image-to-Video (I2V) Chaining Mode**:
- **Step 1:** Shot 1 is generated by Gemini Omni Flash ➔ `shot_1.mp4`.
- **Step 2:** The **OpenCV Video Parser** (`src/tools/video_parser.py`) seeks to Frame #100 (second 10) of `shot_1.mp4` and extracts `shot_1_last_frame.png` as a Base64 string.
- **Step 3:** The Base64 string is passed as `input_image` alongside Shot 2's motion prompt into Gemini Omni Flash (`gemini-omni-flash-preview`).
- **Result:** Shot 2 begins from the exact pixel state and pose where Shot 1 ended, guaranteeing unbroken motion continuity across scene cuts!
